# 客户簿 bank-tool

银行客户信息管理工具（自用）：客户资料、资产记录、拍照 OCR 录入、AI 分析报告，一个手机浏览器就能用。

## 功能

- **客户管理**：资料（姓名/电话/单位/生日/风险等级）、偏好标签与描述、备注，支持搜索和多条件筛选
- **OCR 录入**（调 GLM-5.3-Flash 视觉能力），三种模式：
  - 名片/客户资料 → 提取基本信息，一键新建客户或并入已有客户
  - 系统截图 → 按自定义字段模板提取（适配各类业务系统页面截图）
  - 资产表格 → 多行识别，核对后批量导入资产记录
- **资产表格**：按客户/类别/起止日期筛选，分类汇总与占比，一键导出 Excel；手机卡片式、宽屏自动切表格
- **AI 分析**（默认 GLM-5.3-Flash，可切 GLM-5.3）：客户偏好画像 / 资产配置分析 / 理财营销参考；多选客户可做客群组合分析；发送前默认脱敏（姓名→张客户A、电话打码）
- **AI 对话 + 语音速记**：与 AI 流式对话（口述整理、问客户库、聊业务）；点 🎤 说话转文字；三种关联模式——AI 自动识别消息谈到的客户并归档 / 提到未建档人名一键新建归档 / 手动关联指定客户；归档内容出现在客户详情「沟通记录」
- **PWA**：手机浏览器「添加到主屏幕」，像 App 一样全屏使用

## 技术栈

- 前端：Vue 3 + Vite + Vant 4 + Pinia + SheetJS
- 后端：Node.js 22（内置 `node:sqlite`，零原生依赖）+ Express + multer
- AI：智谱开放平台（OpenAI 兼容接口，`base_url` 可改可换供应商）

## 快速开始（本机开发运行）

要求 Node.js ≥ 22.13（使用内置 SQLite，无需编译原生模块）。

```bash
npm install          # 安装依赖
npm run dev          # 同时启动 API(3010) 和 Vite(5173)
```

开发时访问 http://localhost:5173（自动代理 API）。

### 生产运行（单进程）

```bash
npm run build        # 构建前端到 web/dist
npm start            # Express 同时托管页面和 API，端口 3010
```

访问 http://localhost:3010。

## 配置 AI

1. 到 [open.bigmodel.cn](https://open.bigmodel.cn) 申请 API Key（有免费额度）
2. 打开本工具「设置」页，粘贴 Key，点「测试连通」

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 识别模型 | `glm-5.3-flash` | 多模态，识图即 OCR，价格约为旗舰 1/10 |
| 分析模型 | `glm-5.3-flash` | 追求更强分析质量可改 `glm-5.3` |
| 接口地址 | `https://open.bigmodel.cn/api/paas/v4` | OpenAI 兼容，可换供应商 |

> **套餐用户注意**：如果你用的是 GLM Coding Plan 等 token 订阅套餐的 Key，接口地址必须改为套餐专属端点 `https://open.bigmodel.cn/api/coding/paas/v4`——走普通端点套餐额度不生效，会报 `429 / 1113 余额不足`。套餐端点下 `glm-5.3` 与 `glm-5.3-flash` 均可正常调用。

## 手机上使用

1. 电脑/服务器启动服务后，手机连同一 WiFi，访问 `http://服务器局域网IP:3010`（用 `ipconfig` / `ifconfig` 查 IP）
2. 浏览器菜单里选「添加到主屏幕」，即可全屏类 App 使用
3. **想用语音输入（对话页 🎤 按钮）必须 HTTPS**：浏览器的麦克风与语音识别只在安全上下文开放。给 NAS 配好反向代理 + 域名/自签证书后，通过 `https://你的域名` 访问即可；在此之前对话页可正常打字使用（页面会给出提示）

## Docker / NAS 部署

```bash
npm run build        # 先构建前端产物
docker compose up -d --build
```

- 数据全部在 `./data` 目录（SQLite 库 + 上传图片），**备份就是备份这个目录**
- HTTPS：建议由 NAS 自带的反向代理（群晖/威联通）处理，配好域名和证书后转发到 3010

## 安全须知（重要）

- 本工具**没有登录鉴权**，仅限个人使用。请只部署在可信网络环境（家庭内网、VPN 或只有自己知道的地址），**不要直接暴露公网 IP 端口**
- 客户资金信息属敏感个人信息：AI 分析默认脱敏发送；OCR 识别需要发送原图，界面有提示
- 请遵守所在机构对客户数据的管理规定使用本工具

## 常见问题

- **语音按钮不可用/提示不支持？** 语音识别要求 HTTPS（或 localhost）访问，见上文「手机上使用」第 3 步；打字输入不受影响
- **对话没有自动归档？** 确认对话页关联条为「AI 自动识别客户并归档」模式；AI 匹配依赖客户库中已有客户姓名，提到的完全新人名会出现「新建并归档」按钮，点确认才建档
- **OCR 识别不准？** 拍照尽量端正、光线充足、表格完整入镜；系统截图直接截屏比拍照效果好
- **提示未配置 API Key？** 到「设置」页填写并保存
- **想换模型/供应商？** 设置页可改模型名和接口地址（OpenAI 兼容格式均可）
- **数据在哪/怎么清空？** 全在 `data/bank-tool.db`；删除该文件即清空全部数据
